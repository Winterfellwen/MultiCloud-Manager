# CloudOps AI 全面审计实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 对 CloudOps AI 进行 6 维度全方位审计，输出结构化审计报告

**方法：** 功能遍历 → 截图取证 → 对标分析 → 差距评级 → 写入报告

**参考平台：** AWS Console、Azure Portal、GCP Console

**优先级定义：** P0(紧急/影响核心体验) / P1(重要/中长期改进) / P2(锦上添花)

**交付物：** `docs/superpowers/audits/2026-07-17-cloudops-ai-audit-report.md`

---

### Task 1: UI/UX 审计 — 导航与框架

**范围：** Layout、Sidebar、Topbar、路由过渡、全局响应式

- [ ] **步骤 1：检查侧边栏导航**
  - 打开页面，截取侧边栏截图
  - 检查：层级深度、展开/收起状态、激活态高亮、图标一致性
  - 记录问题到审计报告

- [ ] **步骤 2：检查 Topbar**
  - 截图 Topbar（用户头像、语言切换、通知铃铛）
  - 检查：通知未读数、用户菜单、语言切换体验

- [ ] **步骤 3：检查全局响应式**
  - 缩小浏览器宽度，检查侧边栏折叠行为
  - 检查：移动端是否可用、内容是否溢出

- [ ] **步骤 4：检查主题一致性**
  - 切换 dark/light 模式（如有），检查各页面主题表现
  - 记录不一致之处
